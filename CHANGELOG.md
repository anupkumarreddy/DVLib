## [0.1.0] - 2026-08-12

### Added

- SystemVerilog/UVM package manifests, semantic-version resolution, lockfiles,
  deterministic archives, package installation, and simulator filelists.
- FastAPI and SQLite registry with authenticated publishing and yanking.
- CLI workflows for publishing, installing, updating, searching, and inspecting
  packages.
- Public project documentation, MIT licensing, automated tests, packaging
  validation, dependency auditing, and container smoke checks.
